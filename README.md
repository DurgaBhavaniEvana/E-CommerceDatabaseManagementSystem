🛒 E-Commerce Database Management System (SQL Project)
📖 Project Overview

This project is designed to simulate the working of an e-commerce platform using SQL. It demonstrates how real-world online shopping systems (like Flipkart or Amazon) manage large volumes of data related to customers, products, orders, shipping, and payments.

The main goal of this project is to create a relational database that ensures data consistency, accuracy, and easy retrieval for analysis and reporting.

🧩 Database Design

The project consists of the following tables:

Customers – Stores customer information (ID, name, and state).

Products – Holds product details such as price, cost, brand, and category.

Sales – Records order data including customer, product, order date, and quantity.

Shippings – Manages delivery information like shipping provider, date, and status.

Payments – Tracks payment details including payment date and status.

Each table is linked using Primary and Foreign Keys, ensuring strong data relationships and referential integrity.
